1. What does "key presses bubble up" mean?
This is called Event Bubbling in JavaScript.

Event bubbling means when an event happens on an inner HTML element, that event can travel upward through its parent elements.

2. What is localStorage?
localStorage is a browser storage feature that allows JavaScript to save data in the user's browser.

It can keep data even after the user closes the browser and opens it again.
Example

localStorage.setItem("username", "Gautam");
