postman :-Postman is a software tool used by developers to test a website's backend API without creating the frontend 

Follow these steps:
1. Click Download Postman above.

2. On the official website, choose the Windows desktop app.

3. Wait for the installer to download.

4. Open your browser's Downloads folder by pressing Ctrl + J.

5. Open the downloaded Postman installer (.exe).

6. Follow the installation instructions and open Postman.

7. If asked to sign in or create an account, follow the options shown on screen.

API:- What is an API?
 API stands for Application Programming Interface.
An API allows two software applications to communicate and exchange data with each other.

For example, when you register on a website, the frontend sends your name and email to the backend through an API

3. What does an API look like?
An API can have a URL called an endpoint.

FOR EXAMPLE:-http://localhost:3000/api/students

Here:
- 
localhost means your own
computer.
- 3000 is the port on which your backend is running.
-
/api/students is the endpoint for student-related operations.


Method    |     Purpose            |     Example

GET          |   Retrieve data     | Get all students

POST       |  Create data          | Register a student

PUT          |   Update data       | Update student details
 
DELETE |    Delete data        | Delete a student


API: The communication interface between your frontend and backend.




Postman: A tool for testing your API.




Node.js: Runs the backend code that handles API requests.
