NOT NULL  :  -  The NOT NULL constraint enforces a column to NOT accept NULL values. This enforces a field to always contain a value, which means that you cannot insert a new record, or update a record without adding a value to this field.


SQL Date Data Types
Different SQL databases have various data types to store date and time values.

MySQL has the following date data types:

DATE - format YYYY-MM-DD
DATETIME - format: YYYY-MM-DD HH:MI:SS
TIMESTAMP - format: YYYY-MM-DD HH:MI:SS
TIME - format: HH:MI:SS
YEAR - format YYYY or YY
SQL Server has the following date data types:

DATE - format YYYY-MM-DD
DATETIME - format: YYYY-MM-DD HH:MI:SS
SMALLDATETIME - format: YYYY-MM-DD HH:MI:SS
TIME - format: HH:MI:SS
TIMESTAMP - format: a unique number
Note: The date data type are defined for a column upon creation of a new table in your database.

DEFAULT: he DEFAULT constraint is used to automatically insert a default value for a column, if no value is specified.

The default value will be added to all new records (if no other value is specified).



TheUNIQUE  :-- UNIQUE constraint ensures that all values in a column are unique.

Both the UNIQUE and PRIMARY KEY constraints provide a guarantee for uniqueness for a column or set of columns. However, you can have many UNIQUE constraints per table, but only one PRIMARY KEY constraint per table.



Signup page
:-
User enters name, email and password. The backend hashes the password and saves the account in users.







Login page
:-
User enters email and password. The backend finds the account and verifies the password against password_hash.






Forgot Password page
:-
User enters their email. The backend sends a time-limited reset link, verifies the token, and saves the newly hashed password in users
